What these readings mean
  • VR application FPS measures frames submitted through Virtual Desktop's OpenXR runtime. It is not the headset's displayed frame rate, and can differ with alternate-eye rendering or reprojection.
  • Application CPU/GPU timings come from that runtime. Its GPU timer may cover only part of GTA's rendering path; compare it with frame pacing and overall GPU load.
  • Encoder time is NVIDIA's average hardware encoder latency across active encoder sessions. It is not Virtual Desktop's complete encoding latency. Network traffic includes other applications.
  • Capturing events has some overhead. The CSV includes this recorder's CPU and memory use, but cannot measure the extra work that tracing adds inside the runtime.
